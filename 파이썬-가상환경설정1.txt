1. 파이썬 다운로드
Python Releases for Windows Python 3.11.9

1. Visual Studio code 다운로드
https://code.visualstudio.com/download   
Windows x64

# 가상환경을 처음 구성했을 때 pip 업그레이드
python -m pip install --upgrade pip

2. C:\ragchatbot-project 디렉토리 생성

3. 가상 환경 생성
    python -m venv [가상 환경 이름]
                       
C:\ragchatbot-project> python -m venv venv
→ 현재 디렉토리에 venv/ 폴더가 생성됩니다.

4. 가상환경 활성화(activate)
C:\ragchatbot-project> venv\Scripts\activate

5. 가상환경에서 패키지 설치
(venv) C:\ragchatbot-project> pip install langchain-core==0.2.41 langchain==0.2.16 langchain-openai==0.1.23 langchain-community langchain-text-splitters
(venv) C:\ragchatbot-project> pip install langchain-openai>=0.2.0
(venv) C:\ragchatbot-project> pip install pypdf
(venv) C:\ragchatbot-project> pip install faiss-cpu
(venv) C:\ragchatbot-project> pip install streamlit
(venv) C:\ragchatbot-project> streamlit --version

6. C:\ragchatbot-project> .env 파일을 만들고  OPENAI_API_KEY 키를 설정한다.
OPENAI_API_KEY=sk-proj-RkvAo***


# Streamlit을 사용하여 Python 파일을 실행하는 명령어
(venv) C:\ragChatbot-project> streamlit run rag_chatbot.py
