2. C:\chatbot-project 디렉토리 생성

3. 가상 환경 생성
    python -m venv [가상 환경 이름]
                       
C:\chatbot-project> python -m venv venv
→ 현재 디렉토리에 venv/ 폴더가 생성됩니다.

4. 가상환경 활성화(activate)
C:\chatbot-project> venv\Scripts\activate

5. 가상환경에서 패키지 설치
(venv) C:\chatbot-project> pip install langchain-core==0.2.41 langchain==0.2.16 langchain-openai==0.1.23
(venv) C:\chatbot-project> pip install langchain-openai>=0.2.0
(venv) C:\chatbot-project> pip install streamlit
(venv) C:\chatbot-project> streamlit --version

6. C:\chatbot-project> .env 파일을 만들고  OPENAI_API_KEY 키를 설정한다.
